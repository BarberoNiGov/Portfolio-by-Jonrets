How I Build

Specification, architecture, and verification are mine. Implementation runs through a custom agent harness.

1

Write the spec

Acceptance criteria that can be checked by a command or an observation — never adjectives.

2

Hand off with context

A fresh agent gets the plan, the current state, the next action, and what not to touch.

3

Verify, then ship

A separate pass checks the result against the written criteria. Not against its own memory.

One specification, five systems — adapted, not copied.
